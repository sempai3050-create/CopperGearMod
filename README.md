# Equipo de cobre

Mod para **Minecraft Java 1.20.1** y **Minecraft Forge 47.4.x** que agrega nueve objetos fabricables:

- Casco, pechera, pantalones y botas de cobre.
- Espada, pico, hacha, pala y azada de cobre.

Incluye texturas originales para los iconos y para la armadura equipada. No incluye texturas oficiales de Minecraft. Las estadísticas de cobre se basan en las de Java 1.21.9, adaptadas a Forge 1.20.1.

## Características

- Recetas con lingotes de cobre y palos, siguiendo los patrones habituales de Minecraft.
- Las recetas se desbloquean en el libro al recoger un lingote de cobre.
- Las herramientas se reparan con lingotes de cobre.
- El equipo aparece en las pestañas Combate y Herramientas y utilidades del inventario creativo.

## Instalación

1. Instala Minecraft Java 1.20.1 y Forge 47.4.x.
2. Descarga `coppergear-1.0.0.jar` desde la sección **Releases**.
3. Copia el JAR a la carpeta `mods` de tu instalación de Minecraft.

## Compilar desde el código

Se necesita Java 17. En Windows, abre PowerShell en esta carpeta y ejecuta:

```powershell
.\gradlew.bat build
```

El JAR se genera en `build/libs/coppergear-1.0.0.jar`.
